# GG Sports — Free Deployment Guide

Deploy the site on **free** tiers:
- **Frontend (Next.js)** → [Vercel](https://vercel.com) (free Hobby plan)
- **Backend (Express API)** → [Render](https://render.com) (free web service)
- **Database** → SQLite (stored on the Render service; **resets on every redeploy** — fine for a demo)

> ⚠️ The project must be on GitHub first: `ragulm16/gg-sports` (already done for the
> website code; this guide adds the deployment config files).

## Architecture

```
Browser
  └─ Vercel (next start, server-side rendering)
       ├─ pages fetch → https://<backend>.onrender.com/api/v1/...   (server-side, no CORS)
       └─ admin dashboard & roadmap fetch → https://<backend>.onrender.com/api/...  (client-side, CORS checked)
Render (Express + Prisma + SQLite)
  └─ endpoints: /health, /api/content, /api/v1/content, /api/roadmap, /api/leads, /api/admin/*, /api/auth/*
```

## Part 1 — Deploy the backend on Render (free)

1. Push this repo (with `render.yaml`, `DEPLOYMENT.md`) to GitHub:

   ```bash
   cd ~/Desktop/gg-sports
   git add -A
   git commit -m "chore: add free-tier deployment config (Render + Vercel)"
   git push origin main
   ```

2. Go to [dashboard.render.com](https://dashboard.render.com) → sign in with GitHub.

3. Click **New → Blueprint** → **Connect a repository** → pick **`gg-sports`**.

4. Render reads `render.yaml` and creates the **`ggsports-api`** web service.

5. **Before it finishes** (or right after, then **Manual Deploy → Deploy latest commit**), set in
   **Environment** (under the service → Environment tab):
   - `ADMIN_PASSWORD` → a strong password for the admin dashboard (seeded admin login)
   - `CORS_ORIGIN` → your frontend URL. First change it after Part 2 to
     `https://<your-app>.vercel.app` (comma-separate multiple origins if you add a custom domain).
   - `JWT_SECRET` → already auto-generated by Render (leave as is).

6. Wait for the deploy. Your API URL will be **`https://ggsports-api.onrender.com`**
   (or whatever name Render picked). Verify it:
   ```
   curl https://ggsports-api.onrender.com/health
   # {"service":"gg-sports-api","status":"healthy"}
   ```

> ⚠️ **Free-tier caveat:** Render free services sleep after ~15 min idle (first request
> after sleep can take ~30–60 s) and the SQLite file (`prisma/dev.db`) is **wiped on every
> redeploy/restart**. Admin edits and leads are demo data only.

## Part 2 — Deploy the frontend on Vercel (free)

1. Go to [vercel.com](https://vercel.com) → **Sign up / Continue with GitHub**.

2. Click **Add New… → Project** → import **`ragulm16/gg-sports`**.

3. Vercel auto-detects **Next.js**. In **Project Settings → Environment Variables** add:

   | Key                        | Value                                 |
   | -------------------------- | ------------------------------------- |
   | `NEXT_PUBLIC_API_URL`      | `https://ggsports-api.onrender.com`   |

   `NEXT_PUBLIC_API_URL` is baked in at **build time**, so set it before deploying.

4. Click **Deploy**. Vercel builds and gives you a URL:
   **`https://gg-sports-<something>.vercel.app`**

## Part 3 — Wire them together

1. Copy the Vercel URL, then back in **Render → Environment**, set
   `CORS_ORIGIN=https://gg-sports-<something>.vercel.app` and click **Manual Deploy → Deploy
   latest commit**.
2. Open the Vercel URL → the site should load with content served by your Render API.
3. Check the admin dashboard at `https://gg-sports-<something>.vercel.app/admin` and log in with
   `admin@ggsports.in` + the `ADMIN_PASSWORD` you set on Render.
   (If the admin shows “API URL is not configured”, the `NEXT_PUBLIC_API_URL` env var is missing.)

## Custom domain (optional, free)

- **Vercel:** Project → Settings → Domains → add your domain (HTTPS via Let's Encrypt, free).
- Add that domain to `CORS_ORIGIN` on Render as well.

## Local development (unchanged)

```bash
# terminal 1 — API
cd backend && cp .env.example .env && npm install && npm run dev   # http://localhost:4000

# terminal 2 — website
npm install && npm run dev                                          # http://localhost:3000
```

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| `{"error":"Internal server error"}` in admin | `JWT_SECRET` not set on Render → set it in Environment |
| Admin dashboard says API URL not configured | Add `NEXT_PUBLIC_API_URL` on Vercel and redeploy |
| Admin API calls blocked in browser console (CORS) | `CORS_ORIGIN` on Render must include the exact browser origin (no trailing `/`) |
| First load of the site is slow | Render free service was asleep — it wakes on the first request |
| Content stuck on the fallback cards | API unreachable from Vercel — check `/health` and the env var |
